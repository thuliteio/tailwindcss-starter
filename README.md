# tailwindcss-starter

Official Tailwind CSS starter

## Getting started

Use the CLI:

```bash
npm create thulite@latest -- --template tailwindcss
```

With recommended integrations  (SEO and Images):

```bash
npm create thulite@latest -- --template tailwindcss-rec
```
